After any UI change:
1. Start the dev server and open every affected page.
2. Screenshot each page at 375px, 768px, and 1440px.
3. Review each screenshot for layout breakage, overlapping
   elements, clipped or overflowing text, and low contrast.
4. Fix what you find, re-screenshot, and confirm the fix.
Do not mark the task done until the screenshots look correct.
